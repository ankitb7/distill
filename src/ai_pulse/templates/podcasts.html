How podcasts work

Podcasts are generated using Claude (script) + edge-tts (audio). Manually added articles (via Add Links) are always included in weekly podcasts. Article content is fetched on-demand from original URLs — nothing is stored permanently.

CLI usage:

  • ai-pulse podcast — weekly (top articles + manual)
  • ai-pulse podcast --articles 1,2,3 — on-demand

TTS providers:

  • edge-tts (default) — free, no API key needed
  • openai — higher quality, requires OPENAI_API_KEY
