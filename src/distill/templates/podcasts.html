How podcasts work

Manually added articles (via Add Links) are always included in weekly podcasts. Article content is fetched on-demand from original URLs.

Current provider: {{ provider|default('gemini-api-tts') }} {% if provider == 'edge-tts' %} (Claude script + Microsoft edge-tts — free, ~3-5 min generation time) {% elif provider == 'podcastfy-edge' %} (Your selected AI provider writes the conversation; Microsoft Edge voices create the audio) {% elif provider == 'gemini-tts' %} (Claude script + Google Gemini voices through the official Cloud Text-to-Speech API) {% elif provider == 'gemini-api-tts' %} (Claude script + Gemini Flash voices through the official Gemini API; free-tier audio quota applies) {% endif %}

CLI usage:

  • distill podcast — weekly (top articles + manual)
  • distill podcast --articles 1,2,3 — on-demand
  • distill podcast --provider podcastfy-edge --script-provider anthropic — Podcastfy with Claude and Edge voices

Podcastfy setup: uv run distill podcast-setup. Configure provider keys in .env and models in config.yaml. Edge uses Microsoft’s hosted speech service.
